# Portfolio di ingegneria — Nicolò Nicoletti

Questo pacchetto contiene una prima versione **statica** e responsive del portfolio in inglese. Non richiede build, librerie né servizi a pagamento.

## Pubblicazione su GitHub Pages

L'account GitHub collegato è `niconicoletti01`. Il repository consigliato per il sito personale è **`niconicoletti01.github.io`** (pubblico).

1. Su https://github.com/new crea un repository pubblico con nome esatto `niconicoletti01.github.io`. Se vuoi, seleziona "Add a README file"; non è necessario se carichi prima `index.html`.
2. Apri il repository, scegli **Add file → Upload files** e carica `index.html` nella radice del progetto.
3. Vai su **Settings → Pages**, scegli **Deploy from a branch**, `main`, cartella `/ (root)` e salva.
4. Una volta pubblicato, l'indirizzo sarà `https://niconicoletti01.github.io/`.
5. Inserisci il sito nella sezione Contatti e In primo piano di LinkedIn e nel tuo CV.

Se preferisci, dopo la creazione del repository possiamo caricare il sito attraverso il collegamento GitHub già attivo in ChatGPT.

## Revisione da fare prima di pubblicare

- Verificare ogni descrizione con i materiali originali e la reale ripartizione del lavoro nei progetti di gruppo.
- Confermare la possibile divulgazione delle attività svolte presso SUPSI e del technical assessment ETH. **Non caricare** disegni originali ETH, report integrale, ZIP, materiale di altri studenti, screenshot aziendali o foto dei laboratori senza autorizzazione.
- Le illustrazioni del sito sono **grafiche illustrative originali** e non foto o rendering dei progetti. Inserire in futuro foto/screenshot autentici autorizzati aumenta la credibilità.
- Il CV di esempio usa i livelli linguistici del documento disponibile (inglese B2, tedesco A2); aggiornare solo con livelli realmente sostenibili.
- Il link a LinkedIn e l'email provengono dai materiali CV disponibili. Verificare che l'URL di LinkedIn sia quello corretto.
